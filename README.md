 🏥 Hospital Management System
 Description

This project is a **Hospital Management System** built using **MySQL**. It is designed to manage and organize hospital data efficiently, including patient details, doctor information, appointments, billing, medical records, admissions, and test reports.

The system demonstrates core **Database Management System (DBMS)** concepts through a real-world application.


🎯 **Features**

* 👤 Patient Management
* 👨‍⚕️ Doctor & Department Management
* 📅 Appointment Scheduling
* 📋 Medical Records
* 💰 Billing System
* 🏨 Admissions Management
* 🧪 Test Reports
* 🔐 Role-Based Access Control
* ⚡ Views and Triggers for automation



🧠**DBMS Concepts Used**

* ER Diagram
* Relational Model
* Normalization (up to 3NF)
* Functional Dependencies
* SQL Joins and Nested Queries
* Views
* Triggers
* Primary Key & Foreign Key Constraints


💻 **Technologies Used**

* MySQL
* SQL


🗂️ **Database Tables**

* Patient
* Doctor
* Department
* Appointment
* Medical_Record
* Billing
* Admissions
* Test_Reports


🚀 **How to Run**

1. Create database:

   ```sql
   CREATE DATABASE Hospital_Management;
   USE Hospital_Management;
   ```

2. Run SQL files:

   * schema.sql
   * views.sql
   * triggers.sql

3. Import CSV files using:

   ```sql
   LOAD DATA INFILE ...
   ```
