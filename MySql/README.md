# 🏥 Hospital Management System (DBMS Project)

## 📌 Description

This project is a database system designed to manage hospital operations such as patients, doctors, appointments, billing, and medical records.

## ⚙️ Technologies Used

* MySQL
* SQL

## 🧩 Features

* Patient & Doctor Management
* Appointment Scheduling
* Billing System
* Medical Records
* Views and Triggers
* Role-based Access Control

## 🗂️ Database Tables

* Patient
* Doctor
* Department
* Appointment
* Medical_Record
* Billing
* Admissions
* Test_Reports

## 🚀 How to Run

1. Create database:

   ```sql
   CREATE DATABASE Hospital_Management;
   USE Hospital_Management;
   ```
2. Run `schema.sql`
3. Import CSV files
4. Run `views.sql` and `triggers.sql`
